# What's new in v1.2.0.0

## 2026-10-31

More guidance and improved tools for exploring and reindexing Sitevision content.

### Added

- **User guide:** Added a built-in guide, accessible from the popup.
- **Properties:** Added an Online/Offline switch while exploring node properties.
- **Reindex (~~EXPERIMENTAL~~):**
  - Added support for files and images in repositories, plus structure and collaboration-group pages.
  - Reindexing is no longer considered experimental.

### Changed

- **Properties:**
  - Renamed **Current page** to **Current node**. Outside edit mode, it uses `window.sv.PageContext.pageId`; in edit mode, it prefers the most specific node ID in the URL or the matching entry in `window.editor.appContext.lastNode`. If no node resolves, **Current node** is unavailable.
  - The popup defaults to Offline in edit mode and Online otherwise; the selected version is retained during node navigation and browser history.
- **Reindex:**
  - Preview now distinguishes `robotsIndex=false` skips from unsupported nodes and updates its summary when the override changes. **Start Reindex** reuses a completed preview for the same tab, site, and root.
- **Release notes:** Added links between the guide and release notes; the version link in Options opens release notes in a new tab.

### Removed

- **Properties:** Removed cached node-property responses from browser history. Returning to a previously viewed node now fetches its properties again.

### Fixed

- **Session parameters:** Non-404 HTTP errors are now treated as failed updates, so the popup can report the failure and restore the toggle.
- **Properties:** A slower response from an earlier node navigation no longer replaces the currently selected node.
- **Loading:** The indicator remains visible until overlapping operations have finished.
