# What's new in v1.0.0.0

## 2026-09-02

Initial release of Sitevision Utilities Extension.

### Added

- **Node properties:** Inspect the current page, current user, or a custom node ID via the Sitevision REST API, with clickable node ID traversal.
- **Session parameters:** Toggle the `profiling`, `jsdebug`, and `slimRender` flags with optional auto-reload.
- **Consent cookie:** Decode the `sv-cookie-consent` cookie to inspect accepted/denied cookies, with an option to clear it.
- **Options page:** Configure JSON syntax highlighting, selectable themes, and auto-reload behavior.

### Support

- Chromium (Chrome, Edge, Brave) and Firefox.
