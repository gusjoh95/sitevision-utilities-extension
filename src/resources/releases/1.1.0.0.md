# What's new in v1.1.0.0

## 2026-09-XX

New feature, improved stability.

### Added

- **Find login:** New feature that searches a list of endpoints to locate the site's login page, including support for custom login paths, detecting external identity-provider redirects, and Basic Auth prompts on common WebDAV paths.
- **Options:** Quick link to the extension options added to the popup.
- **Tooltip:** Hover/focus tooltips added to popup and options controls (find-login, open-options, custom login paths, highlight JSON, edit-mode notices) that previously had none.

## Changed

- **Themes:** Six new JSON color themes added (`neon-noir`, `pastel-sunset`, `matrix-glow`, `solar-flare`, `retro-wave`, `aurora-borealis`).
- **Readability:** Improved spacing and key emphasis when viewing JSON, making it easier to tell keys and values apart.
- **Feedback:** Toggling a session parameter now shows a loading state on the checkbox and reverts automatically if the change fails.
- **Reliability:** If the page you're inspecting becomes unavailable (tab closed, navigated away, or permissions revoked), the extension now shows a clear warning instead of breaking, and keeps showing the last loaded properties.

## Deprecated

- Chrome and Chromium-based browsers (Edge, Brave, etc.) now require version 147 or newer.

## Removed

- Session parameters (profiling, jsdebug, slimRender) can no longer be toggled while editing a page; the checkboxes are disabled in this mode.

## Fixed

- Fixed session parameter updates failing on 404 pages.
- Fixed the checkboxes showing the wrong state (jsdebug always appearing checked) while editing a page.
- Fixed the options page having a fixed width that could cause a horizontal scrollbar; input fields now resize better.
